# DesignProAI Generation OS kernel

## Definite chief aim

Produce print-ready wrap panels from one accepted A.T.L.A.S. creative authority. The seven 3D proofs, RevisionStudioIQ, PanelProStudio, QC, production output and WrapBox remain descendants of the same Generation ID and accepted A.T.L.A.S. revision.

## Identity

- `generationId` is the immutable job root.
- `revisionId` / `revisionSequence` identify immutable A.T.L.A.S. versions under that job.
- `masterContentHash` is the canonical creative lineage identity.
- workflow `runId`, stage receipts and artifacts are descendants of the revision that spawned them.
- no browser route or operator action is allowed to substitute a different Generation ID between Design, RevisionStudioIQ, PanelProStudio, QC and WrapBox.

## Execution

The existing server dependency graph remains authoritative. This kernel does not replace it with a linear UI state machine. Independent nodes may run concurrently when their declared dependencies are satisfied.

A.T.L.A.S. Call 1 is the creative root. 3D proofs are conditioned from the A.T.L.A.S. surface authority. Call 9 promotes deterministic Call-1 panel descendants; it is not a second creative producer. Production output may enhance/upscale those files but may not redesign them.

## Persistence

The OS event ledger is append-only and Generation-ID locked. It records:

- A.T.L.A.S. revision creation;
- workflow-run creation/state transitions;
- graph-node creation/state transitions;
- artifact creation;
- verified receipt creation.

The canonical `designpro_generation_os_snapshot(generation_id)` read model returns the current revision, all revisions, workflow runs and stages, artifacts, receipts, events and a server-derived phase for the same Generation ID.

## UI contract

Design, RevisionStudioIQ, PanelProStudio, QC and WrapBox must consume one Generation-ID lineage. UI labels may summarize server state but must never become workflow authority.

## Production authority

PanelPro preflight verifies each production panel against its frozen Call-1 A.T.L.A.S. source panel and accepted-master lineage. A Call-8 proof region is never production artwork authority.

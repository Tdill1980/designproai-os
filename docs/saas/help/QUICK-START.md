# DesignProAI Quick Start — From Prompt to Production Files

This guide is written for daily users. It focuses on the normal path through the operating system.

## 1. Start the right kind of project

Choose the application that matches the job:

- **VehiclePro** — create vehicle graphics for a known year/make/model.
- **MyVehiclePro** — work from photos of the customer's actual vehicle.
- **WallPro** — create wall/environmental graphics.
- **CutPro** — create or prepare cut graphics.
- **RecreatePro** — start from customer-supplied visual direction that needs to be rebuilt into a usable project.

DesignProAI creates/maintains the project identity behind the app.

## 2. Describe the design

Use natural language to tell **A.C.E. — AI Creative Engine** what the customer wants.

Include what matters:

- business/brand;
- required wording;
- colors;
- style;
- desired mood;
- important placement direction;
- supplied logos/artwork;
- reference images;
- vehicle/wall context.

You do not need to write an AI-engineering prompt. Describe the job the way you would brief an experienced designer.

## 3. Review the design in context

For vehicle work, review the photorealistic views for the selected year/make/model or the actual-vehicle workflow when using MyVehiclePro.

Use the proof to evaluate:

- hierarchy;
- readability;
- visual balance;
- brand accuracy;
- contact information;
- major placement decisions.

A presentation proof is for design review. Final production geometry is validated later by the production system.

## 4. Send the proof to the customer

Open the project in **RevisionStudio** and send/share the design proof with the customer.

Keep customer review inside the project whenever possible. This preserves the relationship between the proof, requested changes, approval, and future production output.

## 5. Make revisions

Use RevisionStudio to make or record controlled changes instead of starting a new unrelated design.

Typical revisions:

- logo change;
- phone number/URL;
- copy change;
- color change;
- move/resize a graphic;
- replace a supplied asset;
- update design direction.

A creative change creates revision history while preserving the project lineage.

## 6. Approve the design

Once the design is approved, confirm that the selected revision is the one intended for production.

Do not use an old exported proof as production authority. Production follows the approved project/revision inside DesignProAI.

## 7. Order production-file output

Purchase/order the production-file package from the project/RevisionStudio flow.

The purchase authorizes the production portion of the workflow. DesignProAI then moves the project into server-owned production processing.

## 8. Follow GENIE progress

Open the **GENIE Universal Panelizer** progress page to see the real production progression.

The progress page reflects server-reported state and real artifact availability. A stage is not complete simply because a browser animation moved forward.

## 9. Production geometry and validation

GENIE resolves the production geometry required by the job. Vehicle projects use the GENIE Vehicle Database and other validated project data so production dimensions do not depend on the appearance of the 3D proof.

## 10. PrintPanelStudio QC

The production/design team uses **PrintPanelStudio** for multi-step QC.

The workflow can include:

- compare approved proof to print panel;
- verify the correct project/surface;
- inspect dimensions and file state;
- automated validation checks;
- human preflight approval;
- output verification;
- final human QC.

The exact production output is released only after the required gates pass.

## 11. Receive the production package in WrapBox

After production output is built, verified, and released, the completed package is delivered through **WrapBox**.

WrapBox is the digital file-delivery destination. Printing/shipping happens in the downstream production or fulfillment workflow selected for the job.

## The short version

**Prompt it → Design it → Proof it → Revise it → Approve it → Order it → GENIE prepares it → PrintPanelStudio validates it → WrapBox delivers it.**

# The served single-page application. web/dist is the archive's name for the
# web build; since the branded operator shell replaced the minimal control
# panel, that build is produced from app/. The shell references its own images
# by absolute path, so they are copied out of app/public and land beside the
# hashed bundles rather than inside assets/ -- hence one pattern per extension
# rather than one per directory. `*` spans `/` here, so each pattern covers
# every depth under web/dist.
#
# The extension allowlist is the control: an archive may carry a page, a
# bundle, a stylesheet, a font or an image, and nothing else. Anything
# executable, archived or unrecognised is refused by the validators.
